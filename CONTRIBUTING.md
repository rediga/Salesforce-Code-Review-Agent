# Contributing to Salesforce-Code-Review-Agent

First off, thank you for considering contributing to this repository! It's people like you that make this tool incredibly useful for the Salesforce developer community.

## How to Contribute

### 1. Report Bugs or Suggest Features
If you notice the AI giving bad advice, hallucinating, or missing a critical Salesforce security standard, please open an **Issue** and provide:
- The Salesforce code snippet being reviewed.
- The prompt you used.
- The incorrect AI response.

### 2. Submitting Pull Requests
If you want to add new AI rules or fix existing ones:
1. **Fork** the repository and create your branch from `main`.
2. **Edit** the relevant markdown or configuration files (like `BUGBOT.md` or `.cursorrules`).
3. **Test** your changes locally in your Cursor IDE by reloading the window and running `/review-salesforce`.
4. Submit a **Pull Request** and fill out the provided PR template.

We will review your PR as soon as possible. Thank you for helping us set the bar for AI Salesforce code reviews!
